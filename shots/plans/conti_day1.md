# 1일차 대본과 콘티 검토본 (2026-10-31)

사용자가 2026-10-31 에 확정했다. 대사는 게임에 넣었고, 콘티는 이 문서대로 짓는다. GPT 콘티 초안을 감독이 고쳤다.

한 줄 요약: 답장을 기다리던 사람이, 인사 한마디를 기다려 주는 사람이 된다.
저녁에 인사가 성공하고, 불을 끈 뒤 같은 인사가 실패하며 하루가 닫힌다.

## 주 경로 대본과 콘티

경로: 누구세요 → 고맙다고 전송 → 읽었는지 묻기 → 이야기 듣기 → 천천히 기다리기 → 경계 긋기 → 인사는 좋았어 → 단톡에 답하기.

샷은 `폭 m / 눈선 % / yaw / pitch` 다. M 0.44 / 36 / 0 / 0, L 0.44 / 36 / +12 / 0, C 0.32 / 39 / 0 / 0.
카메라 이동은 컷 8 의 밀기 한 번뿐이다. 나머지는 컷과 정지로 간다. 슬롯마다 강조는 하나다.

"나" 는 플레이어, [선택] 은 플레이어가 고르는 말이다. 〔수정〕 은 지금 게임에 든 대사와 달라지는 줄이다.

## 지금 대본에서 빠지는 것

- 아침의 규칙 장면과 그 응답(주 경로 22줄 → 19줄). 카톡을 읽은 잘못을 "인사 길이 설정" 으로 넘기면 안 되어서 사과에서 닫는다.
- "내가 싫어지게 만들면 안 되지.", "하나만 골라 줘." (반복)

## GPT 제안 중 받지 않은 것

- "네 번째가 제일 솔직하다." 삭제: 놀림이 하린의 매력이라 솔직한 길에 남겼다.
- "골라. 나는 아무 말도 안 했어." 수정: 지운다고 권한 뒤 시치미 떼는 것이 이 줄의 맛이다.
- 슬픈 길의 "...조금은 그렇지만." 삭제: 플레이어를 달래게 하는 부담보다 서툰 귀여움이 크다.
