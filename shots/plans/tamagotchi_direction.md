# 방향 전환: 고양이 같은 여자와 동거하는 다마고치 (2026-10-31)

사용자와 논의해 정했다. 아직 짓지 않았다. 폰 메신저 게임은 멈춘다.

한 줄: 불쌍해서 길에서 주워 온 고양이 같은 여자와 동거한다. 곁을 내주기 시작할 즈음, 그녀가 내 이름을 잊기 시작한다.

## 정한 것

| 항목 | 결정 |
|---|---|
| 장르 | 다마고치식 동거 게임. 전투 없음 |
| 시작 | 비 오는 밤 길에서 하린을 발견해 집에 데려온다. 사정은 나중에 보충한다. 서론은 한 장면이다 |
| 폰 | 앱, AI, 메신저 설정을 뺀다 |
| 하린 | 분명한 성인. 어른 얼굴과 어른 체형. 고양이처럼 시큰둥하고, 실패해도 태연한 척한다 |
| 힘의 관계 | 하린이 우위다. 제 발로 따라왔고 언제든 나갈 수 있다. 플레이어는 고양이에게 지는 집사다 |
| 자라는 것 | 하린이 아니라 둘의 관계. 돌볼수록 새 옷, 새 동작, 가까운 장면이 열린다 |
| 수위 | 옷, 자세, 친밀한 장면까지. 노출과 성행위는 없다 |
| 판매처 | 구글 플레이, Steam 기준 |
| 시간 | 현실 시각에 묶는다. 아무 때나 켜도 그 시간대의 하린이 있다 |

## 하루 짜임

| 때 | 하린 | 플레이어 | 시간 |
|---|---|---|---|
| 아침 | 부스스하게 일어난다 | 인사, 옷 고르기 | 1분 |
| 낮 | 혼자 생활한다 | 없음. 다음에 켜면 흔적이 남아 있다 | 0분 |
| 저녁 | 혼자 한 일을 자랑하거나 실패를 숨긴다 | 밥, 놀이, 대화 | 3분 |
| 밤 | 졸고, 가까워진다 | 재워 주기, 기억 하나 남기기 | 2분 |

## 공간마다 그곳에서만 하는 일

| 공간 | 생활 | 이야기와의 연결 |
|---|---|---|
| 욕실 | 뒤에서 보는 양치, 세수, 머리 말려 주기, 마스크팩으로 놀라게 하기, 치약 다툼 | 쓰지 않는 칫솔. 거울에 붙는 기억 쪽지. 하린이 거울로 나를 힐끔 본다 |
| 부엌 | 냉장고 뒤지기, 라면, 실패한 요리, 몰래 먹기 | 자기 컵처럼 집는 머그잔, 깨진 컵 |
| 침대 | 자리 뺏기, 뒹굴기, 내 옷 입기, 졸기 | 사진 속 하린도 같은 자리에 있다 |
| 현관 | 배웅, 마중, 신발 흩어 놓기, 택배 | 하린의 신발이 있는지가 곧 집을 나갔는지다 |

욕실 문이 닫히면 들어가지 않는다. 하린의 사생활 경계이고 벗은 모습을 보여 주는 장면은 없다.

## 벌칙

| 안 켠 기간 | 하린 | 되돌리기 |
|---|---|---|
| 1일 | 변화 없음 | 필요 없음 |
| 2 → 3일 | 삐쳐서 등을 돌리고 작은 기억 하나가 사라진다 | 곁에 있어 주면 풀린다 |
| 4 → 6일 | 이름을 머뭇거리고 함께한 일을 틀리게 말한다 | 남긴 기억을 들려주면 일부 돌아온다 |
| 7일 이상 | 집이 비어 있다 | 비 오는 정류장에서 다시 찾아온다 |

정류장에서 하린은 "누구세요?" 라고 한다. 친밀도는 일부만 낮추고, 기억 하나는 돌아오지 않는다. 일주일 만에 돌아온 사람이 떠나지 않도록 이 장면은 벌보다 재회로 짓는다.

## 화면 구성

| 맡을 것 | 방식 |
|---|---|
| 방 | 2D 배경 그림 여러 장: 한 평면도에서 나온 시점별 그림(침대 쪽, 부엌 쪽, 현관 쪽, 욕실). 시간대는 색으로만 바꾼다. 대학가 한국 원룸(약 20제곱미터)이고 외국풍 다락방은 쓰지 않는다. 평면도를 먼저 정해 그림끼리 벽, 창, 가구 위치가 맞게 한다. 현관(신발이 보임)과 욕실 문이 보여야 하고, 지금 그림보다 좁고 살림이 많아야 한다 |
| 평소 생활 | 어른 체형 3D, 실내복은 5.5등신, 외출복은 6등신(2026-11-01 사용자 결정). 집 안에서 비율이 높으면 귀여운 맛이 떨어진다. 대기처럼 몸을 크게 돌리지 않는 작은 동작만 쓴다. 현재 모델은 실내복 C48(5.5등신), 외출복 6C-O1-3(6등신) 이다 |
| 큰 동작 | 2D 컷. 넘어지기, 하품, 기지개처럼 옷이 따라가지 못하는 동작이다. Live2D 는 시험 중이다 |
| 표정 개그, 가까운 장면 | 2D 일러스트 컷 |
| 목소리 | 지금 음성 방식 |
